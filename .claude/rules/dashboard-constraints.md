# Dashboard Design Constraints

`docs/DESIGN.md` is the visual contract (color tokens, typography roles, components) and `docs/PRODUCT.md` the product one; both are tracked, while the tooling that generated them is gitignored. These constraints in `ProxyDashboardHtml.kt`, `PathTableHtml.kt` (the Paths view's table), `ActivityHtml.kt` (the Activity view's table), `DashboardScript.kt` (the page's script), `ScrapeNow.kt`, `ProxyDashboardCss.kt`, and `ProxyDashboardService.kt` are load-bearing and easy to undo by accident:

- **The live region must stay outside every `hx-swap-oob` region.** A region the push loop rewrites re-announces itself on every frame. `ProxyDashboardHtmlTest` pins this.
- **The column guide stays outside every `hx-swap-oob` region, and its rows come from the header's own columns.** `renderFilters` renders it under the search, where no push reaches it, so it stays open as `#path-table` (header and all) is replaced every refresh; inside a pushed region it would close on the next frame. Each view builds one `TableColumn` list per render (`PathTableHtml.columns`, `ActivityHtml.columns`), and both the header row (`columnHeaders`) and the guide iterate it, so a column can't reach the header without an explanation; add a column to that list, not to the header row alone. `PathTableHtmlTest` and `ActivityHtmlTest` pin both.
- **Check a color against `--surface-2`, not `--surface`.** Every token also lands on the tighter ground under tables and section headers, which is where all 29 of the contrast failures fixed in 4.0.1 lived. The measured AA floor is 4.59:1 — `docs/DESIGN.md` records the per-token values.
- **Every layout must render agent identity through `agentLabel()`.** The agent, path, and activity views are read against each other, so a divergent label (or a raw `agentId`) defeats the correlation they exist for.
- **The route base arrives already normalized; do not normalize it again per use site.** `ProxyDashboardService` derives `routeBase` once (trailing slash stripped, so it is empty at a root mount) and hands the same value to its own `routing { }` block and to `renderPage`/`pushFragment`. Sub-routes are then plain interpolation. Re-adding a per-site join helper splits the rule across two layers, which is how the router and the links came to disagree before: the links were fixed while the routes still built `//paths`, and only Ktor discarding empty segments hid it. The nav's own link is the base itself, so it must render as `/` rather than collapse to an empty `href`. `ProxyDashboardHtmlTest` pins both.
- **A scrape-now stays out of what the proxy reports, and every action stays behind `pageGuard`.** `ScrapeNow` submits through `ScrapeDispatch.submitScrapeRequests`, which records nothing; the scrape route (`ProxyHttpRoutes`) records Prometheus's scrapes (`recordScrapeOutcome`, the latency and size metrics, the request counter). Don't record a scrape-now there, or it skews the rates Prometheus alerts on and fills the path's History with scrapes Prometheus never made. Its `ScrapeSpec` (`ScrapeNow.scrapeOf`) carries `ScrapeOrigin.DASHBOARD`, which sets the scrape request's `dashboard_scrape` so the agent counts it in `agent_dashboard_scrapes_total` rather than its `agent_scrape_*` metrics; keep it, or the agent's rates skew the same way. Install `pageGuard` on every route the page's script calls: it checks the Origin and, for anything but a GET, requires the `HX-Request` header, which no other site's page can send without a CORS preflight the dashboard never answers; without it, a link elsewhere could make the proxy act. `ProxyWebDashboardTest` pins both.
- **Served asset URLs carry the WebJar version.** The scripts are cached for a year (`Cache-Control: public, max-age=31536000`), and a reload doesn't revalidate them, so a fixed URL would leave a browser running its cached htmx against the next version's markup. The route and the page's `<script>` tags both build the URL from `ProxyDashboardService.ASSET_DIR` (`assets/<htmx version>`); don't serve an asset outside it. `ProxyWebDashboardTest` pins that the unversioned path 404s.
